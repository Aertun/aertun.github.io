Hunting

aertun hunt --field raw.user_agent [--hours 24]          # the store
aertun hunt --field raw.user_agent --by actor events.jsonl
aertun telemetry fields events.jsonl
aertun triage events.jsonl

A hunt counts one field's values and shows the rarest, which is what is worth a look. With no file it stacks the store's events over the last hours, as the Hunt screen does, and asks for an analyst's reach; with a file, or events piped in, it reads those. The screen offers what you found as the start of a rule.
